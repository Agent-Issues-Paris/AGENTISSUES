## Предзаказ по тегу

Тег `preorder` включает предзаказ. Тема делает три вещи:

- **Текст.** Перед названием выводится «PRE-ORDER: » на странице товара, странице номера, в hero главной, в карточках Shop и в корзине. Если название уже начинается с «pre-order», второй префикс не добавляется.
- **Schema.** Для товара с тегом availability в JSON-LD становится `https://schema.org/PreOrder`. Без тега остаются InStock/OutOfStock, как раньше.
- **Заголовки.** `<title>`, og:title и name в schema префикса не получают.

Текст префикса задан в одном месте: [snippets/product-title.liquid:12](../snippets/product-title.liquid). Логика тега — в [snippets/is-preorder.liquid](../snippets/is-preorder.liquid), JSON-LD — в [snippets/product-schema.liquid](../snippets/product-schema.liquid).

Файлы, которые затронул PR #17: новые `snippets/is-preorder.liquid`, `snippets/product-title.liquid`, `snippets/product-schema.liquid`; изменённые `sections/main-product-issue.liquid`, `sections/main-product.liquid`, `sections/home-hero.liquid`, `snippets/product-card.liquid`, `sections/main-cart.liquid`, `README.md` (раздел Pre-orders).

Проверено: на dev-теме с тегом и без (Issue 01, футболки, Issue 02). Тег на Issue 02 поставлен в админке, на сайте префикс отображается.
