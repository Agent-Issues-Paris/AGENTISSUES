# Agent Issues static site (frozen)

This branch is the headless static version of the Agent Issues shop, served by GitHub Pages at https://agent-issues-paris.github.io/AGENTISSUES/.

**It is being sunset.** No new features go here. All development has moved to the native Shopify theme on the [`shopify-theme`](https://github.com/Agent-Issues-Paris/AGENTISSUES/tree/shopify-theme) branch, which is now the default branch of this repo. Its `CONTRIBUTING.md` explains how to run previews and open PRs.

The site keeps running as it is until the Shopify theme is published. After that, this address will redirect to the shop and the branch will be archived.

Only urgent fixes are accepted here, through a PR, and the same fix has to land in the theme too.
